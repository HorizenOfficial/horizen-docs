# Token Addresses

ZEN is a standard ERC-20 token that lives on Base and bridges across chains via LayerZero's OFT (Omnichain Fungible Token) framework. The token remains active on Base, so these addresses are useful when building on Vela — for example, when depositing or withdrawing allowlisted ERC-20 tokens.
